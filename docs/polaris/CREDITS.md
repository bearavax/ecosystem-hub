## Svalbard heightmap

`public/polaris/svalbard-heightmap-256.png` is a 256×256 grayscale downsample of the Norwegian Polar Institute S0 digital terrain model, 2.5 m, Longyearbyen area (`NP_S0_DTM2_5_2011_25162_33`).

Map data © Norwegian Polar Institute, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The unmodified licence text ships with the file as `public/polaris/NPI_License.txt`.

The terrain is not for navigation. Elevations in the source model run from about 0 m to about 1050 m. This Hub build uses the image only as a displacement map for a simplified 3D view.
